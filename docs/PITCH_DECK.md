# 5. GAMEPLAY LOOP

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│   SPIELEN → PUNKTE SAMMELN → BATTLES → GEWINNEN    │
│       ↑                                    │        │
│       │                                    ↓        │
│       └──── REWARDS EINLÖSEN ←── RANKING ──┘       │
│                                                     │
└─────────────────────────────────────────────────────┘
```

1. **Spielen:** Quiz-Karten swipen, Fragen beantworten
2. **Sammeln:** Punkte verdienen durch richtige Antworten
3. **Battlen:** Punkte einsetzen, gegen andere antreten
4. **Gewinnen:** Battles gewinnen, Punkte verdoppeln
5. **Einlösen:** Punkte im Shop gegen Preise tauschen
6. **Wiederholen:** Motivation durch Rankings & Rewards
